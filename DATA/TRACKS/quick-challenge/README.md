# Quick Challenge Data

**[Download the Quick Challenge ZIP](https://raw.githubusercontent.com/GlassHouse97/AI-Cost-Efficiency-Portfolio-Project/main/DATA/TRACKS/quick-challenge/mru-quick-challenge.zip)**

Extract the package and open **START_HERE.html**. It contains the questions and links to the data in the same folder. It works offline. The [data dictionary](DATA_DICTIONARY.md) defines each source column and is included in the download and in the workbook's **Data Dictionary** worksheet.

| File | Contents |
| --- | --- |
| `START_HERE.html` | Brief business context and the six questions |
| `mru-quick-challenge.xlsx` | Original source data in the **Raw** worksheet, with a separate **Data Dictionary** worksheet |
| `mru_quick_challenge.csv` | The same source records in CSV format |
| `DATA_DICTIONARY.md` | Source column definitions, data types, and units |
| `LICENSE` and `DATA_LICENSE` | Terms for using the materials |

Choose Excel or CSV. They are two formats of the same data for Campaigns 1 and 2.
