# Data Tracks

Choose the track that matches your exercise. Each folder contains its source files, a data dictionary, and one complete download. The dictionary is also included as a worksheet in each Excel workbook.

| Track | Source data |
| --- | --- |
| **[Quick Challenge](quick-challenge/README.md)** | One source worksheet and a matching CSV for Campaigns 1 and 2 |
| **[Portfolio Project](portfolio-project/README.md)** | Four source worksheets and four matching CSVs covering all four campaigns |

The Excel and CSV versions contain the same records. Both tracks use original source data without calculated answers.
